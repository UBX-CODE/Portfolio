## ✧ Key Features

- **Elegant Aesthetics:** A clean, sophisticated light-themed design inspired by editorial layouts.
- **Buttery Smooth Scrolling:** Integrated Lenis for a premium, native-feeling scroll experience.
- **High Performance:** Lightning-fast load times and optimized rendering powered by Vite and React.
- **Fully Responsive:** Flawless visual experience across all devices and screen sizes.
- **Dynamic Interactions:** Engaging micro-interactions utilizing GSAP and Framer Motion.

---

## ✧ Tech Stack

- **Framework:** React + TypeScript
- **Styling:** Tailwind CSS + Vanilla CSS for custom animations
- **Animation:** GSAP, Framer Motion
- **Scrolling:** Lenis
- **Build Tool:** Vite

## ✧ Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/UBX-CODE/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
