## 🌟 About The Project

Welcome to my personal portfolio repository! This project serves as my digital resume, showcasing my skills, projects, and educational background. It is designed with a strong focus on aesthetics and user experience, seamlessly blending modern web design principles with smooth, highly engaging animations.

### ✨ Key Features

- **🚀 High Performance:** Lightning-fast load times and optimized rendering powered by Vite and React 19.
- **📱 Fully Responsive:** Flawless visual experience across all devices and screen sizes.
- **🎨 Modern UI/UX:** Clean, sophisticated dark-themed aesthetics customized with Tailwind CSS.
- **✨ Dynamic Animations:** High-performance scroll effects and micro-interactions utilizing GSAP and Framer Motion.
- **🖱️ Smooth Scrolling:** Integrated Lenis library for a premium, buttery-smooth scrolling experience.
- **🤖 Generative AI Ready:** Includes integration with Google's Generative AI for dynamic, intelligent features.

## 🚀 Getting Started

Follow these simple steps to get a local copy up and running.

### Installation

1. **Clone the repository**
   ```sh
   git clone https://github.com/UBX-CODE/Portfolio.git
   ```
2. **Navigate to the project directory**
   ```sh
   cd Portfolio
   ```
3. **Install NPM packages**
   ```sh
   npm install
   ```
4. **Start the development server**
   ```sh
   npm run dev
   ```
